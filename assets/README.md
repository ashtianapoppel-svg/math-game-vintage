# Carpeta de assets

Sube aquí tus imágenes con estos nombres:

- `background.jpg` - fondo del vagón antiguo
- `object-clock.png` - reloj antiguo
- `object-suitcase.png` - maleta vintage
- `object-gramophone.png` - gramófono antiguo
- `object-phone.png` - teléfono retro
- `doll.png` - protagonista

Cuando tengas todas las imágenes subidas, ejecuta:

```bash
python3 scripts/embed_assets.py
```

Esto generará el archivo final con las imágenes incrustadas en el HTML.
